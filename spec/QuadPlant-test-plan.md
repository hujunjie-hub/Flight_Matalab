# QuadPlant 验证计划

状态：测试代码分批实现；GitHub 静态审查不能代替 MATLAB/Simulink 实际执行。2026-11-09。

## 1. 分级验收

先组件开环，再物理侧开环，最后 MIL 闭环。每个运行结果必须记录参数/模型/场景 Hash、MATLAB 版本、求解器、步长、frame 和精度。以下阈值是 SIM 数学验收值，不是实物精度承诺。

| ID | 试验 | 验收标准 |
|---|---|---|
| P-01 | 0→5 N 电机目标阶跃，1 s | 单调/有限；5 tau 后转速距目标 <1%；推力按 k_f*omega² |
| P-02 | 四路相等推力 | 力矩残差 ≤1e-10 N·m，Fz=-sum(f) |
| P-03 | 单前左电机 1 N | tau_x=-y、tau_y=x、tau_z=gamma，与 FRD 叉乘相符 |
| P-04 | 无推力/无 drag 自由落体 0.1 s，无地面 | Δv_D=g*t，Δp_D=0.5*g*t²，误差 ≤1e-6 |
| P-05 | 恒定 mg 向上合力，无扰动 2 s | 速度漂移 ≤1e-6 m/s，不得重复加 gravity |
| P-06 | q/-q 与非零姿态初值 | 相同物理轨迹；q 范数误差 ≤1e-6 |
| P-07 | 非零杆臂旋转 | IMU/GNSS 天线运动符合刚体解析式，误差 ≤1e-6（理想层） |
| P-08 | 静止水平 IMU | specific force=[0,0,-g]；gyro 包含相应 Earth 项 |
| P-09 | 噪声 seed 重复/独立源 | 同 seed 序列相同；统计 STD 通过 95% 置信区间 |
| P-10 | sensor delay/axis delay | sample/capture/arrival 分别正确；M2 不重复补偿 |
| P-11 | 地面落体/起飞 | 法向力非负、无 NaN/Inf；基准最大穿透 <2 cm |
| P-12 | 积分步长收敛 | 相同输入下，500 μs Simulink RK4 与独立 250 μs RK4 参考比较：位置差 <1e-3 m、姿态差 <1e-4 rad |
| P-13 | loss-of-effectiveness/外力 | 真值改变经物理测量反映，不直接给 M4 传感器故障标签 |
| P-14 | truth 隔离 | 模型依赖图无 truth→Nav/Control 捷径 |
| P-15 | 几何尚未接触但快速下降 | 接触点距地 1 cm、v_D=1 m/s 时 Fn 严格为 0 |
| P-16 | 静态地面支撑 | 压缩量 mg/k 时，总法向力与 mg 一致；初始几何接触状态和静态预压缩状态分开 |
| P-17 | 非法状态/环境输入 | NaN、非法开关、超界效能必须拒绝 |
| P-18 | 坐标变换 | FRD 力旋转到固定 NED；外力矩按 FRD 解释 |
| P-19 | 风阻 | 阻力使用 v_NED-wind_NED，而不是地速本身 |

P-12 只改变物理积分精度，不改变输入保持和初始条件。当前独立参考只覆盖无接触平滑场景，不代表传感器队列/事件时序已通过。

P-11 基准为地面上方 0.1 m、零初速、无推力落体；另设高落差场景，不能把 2 cm 门限外推到任意撞击。P-16 静态压缩量约为 1.5*9.80665/5000≈2.94 mm。初始 PlantState0 的几何接触点无预压缩，会先经历短暂接触稳定过程。

## 3. 系统闭环评价

只有 P-01～P-19 适用项通过、传感器阶段验收且共享 FCS 合格后，才执行 FlightSIM 系统闭环测试。测试高载荷、风、延迟和电机退化，评价估计/控制能力与状态变化；不把 PC 仿真结果标为 Flight Release 或 HIL 实时性 PASS。
