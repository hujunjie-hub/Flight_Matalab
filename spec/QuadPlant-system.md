# QuadPlant 系统规格

状态：SIM_ONLY 功能模型；2026-11-09。属于 FlightSIM 系统的 MIL 物理侧，只有 FMT_MILSIM 激活。

## 1. 用途和证据

为 MPC/SO(3)/Rate PID/分配/FMS 提供可重复的四旋翼软件闭环。已有 MC-Plant 可供结构/公式参考，其默认质量0.886kg、J等来自旧合成模型，未提供本项目实物推力台架、惯量、风场或 ESC 测试，因此不能将旧默认值当实机辨识。

选取固定质量6DOF刚体、四电机一阶转速、保守线性阻力、几何门控接触近似和可控传感器效应。首版不增加未经数据支撑的复杂桨盘、柔性、CFD、真实鸟撞或电化学模型。

## 2. 接口分类

| 类别 | 输入/输出 | 单位/基准 |
|---|---|---|
| u 命令 | 经 M7 虚拟帧提交的四路等效推力 | N，相对 CG 的四电机定义 |
| w 扰动 | 风 NED、外力/力矩、地面、传感器故障脚本 | m/s、N、Nm；显式 frame |
| y 测量 | IMU/固定 GNSS PVT、PPS及历元/Baro/Mag、SIM接地传感器 | 标准样本、独立授时事件和物理 sample time |
| z 真值 | CG p/v/q/ω、电机ω/推力、接触力 | double；只读评价与传感器合成 |

Command→motor→force/torque→rigid body→measurement 的全链必须闭合。PlantTruth 不直接进入 Estimator/FMS/Controller；已配置初态允许同时初始化仿真与估计器，并记录各自先验不确定度。

GNSS 接收机和 PPS 是目标系统固定启用的硬件能力；天空遮挡/卫星信号不可用是场景质量故障，不能删除 GNSS 模型或关闭源配置。目标仿真应由天线运动合成 PVT、由独立时钟场景生成 PPS/UTC，并分别注入失效接受 T-GNSS-01..06 验证，不从机体 truth 直接修改导航能力或源健康。当前 Host SIL 仅实现本地 monotonic PVT 事件，PPS raw capture/UTC mapping 属于 P10b 待实现范围。

## 3. 范围和初始工作点

局部 NED、FRD、CG，名义飞行在原点附近8m窗口，倾角≤25deg、速度≤2m/s、rate≤[2,2,1]rad/s。Origin 设在初始 CG，局部 p0=0、地面 D=0.15m；初值 CG 位于地面上方0.15m，速度0、q单位、ω0、电机0；WGS锚点为明确合成45degN/0degE/100m椭球高，不声称是实际起飞点或AMSL。

| 量 | 当前 SIM_ONLY 基准 | 来源/性质 |
|---|---|---|
| 质量 / 惯量 | 1.5kg / 当前数值 diag[.025,.025,.04]kg·m²；内核支持完整对称正定 3×3 J | Flight/config/vehicle_model.yaml；合成值，无硬件辨识证据 |
| 电机位置 | (+.18,-.18)、(+.18,+.18)、(-.18,+.18)、(-.18,-.18)m | Flight 配置；FRD，按四电机数组顺序 |
| 偏航力矩系数 | [-.02,+.02,-.02,+.02]m | Flight 配置；符号必须按数组顺序 |
| 电机推力上限 / 时间常数 | 15N/路 / .03s | Flight 配置；当前 DShot 量化接口仍限制0..10N |
| k_f | 1e-5 N/(rad/s)² | SIM_ONLY 电机近似，非实测推力曲线 |
| drag / rate damping | diag[.1,.1,.15]kg/s / .002Nm·s/rad | SIM_ONLY 合成阻尼 |
| 地面 k/c | 5000N/m / 100N·s/m；首版水平摩擦系数 μ=0 | SIM_ONLY 合成接触参数；不含水平摩擦 |
| 重力 / Earth rate | 与 Flight Host SIL 重力和 SIM_ONLY Origin 一致 | 共享来源，禁止另写第二份常数 |

真实参数接入前必须有来源、单位、标定条件/误差和版本；本轮不从现有 Plant 默认值推断电机、桨叶或电池型号。刚体内核使用完整 3×3 对称正定惯量矩阵计算 J·ω、ω×(J·ω) 和 J⁻¹角加速度；参数入口拒绝非对称或非正定矩阵。当前 Flight 合成数值恰好为对角矩阵。

## 5. 验收与限制

验收先子系统开环、再集成物理开环、最后 MIL 闭环；详见 QuadPlant-test-plan.md。当前已有 Plant 数学、惯量、失效输入、IMU/天线杆臂和真值隔离测试脚本，但并不代表已在 MATLAB 执行。只有 P-01..21 适用项和共享 FCS 合格，才可把 Plant 用于控制整定。

目标是功能 MIL，不要求实时运行或 VR 渲染；Host 运行慢不能推断固件超时，Host 运行快也不能证明 H723 可用。外层 fixed-step discrete 500us，Plant 内部显式 RK4；传感器延迟、量化 code 和固定500us帧应用延迟进入闭环，不能用理想状态反馈掩盖延迟。
